# Security policy

Please report suspected vulnerabilities privately to the project maintainers.
Do not include ROM files, BIOS files, personal library exports, API tokens, or
unredacted filesystem paths in a public issue. Include a minimal reproduction,
affected version, operating system, and expected versus actual behavior.

The project treats ROMs, DAT files, archives, sidecar metadata, artwork, and
library-import files as untrusted input. Security fixes are released with a
changelog entry and regression test where practical.
